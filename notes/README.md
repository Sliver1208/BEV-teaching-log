# 📒 notes · 文档解析与学习笔记

本目录是整个 BEV 教学工程的**文档解析和学习笔记**存放处，包含三类内容：

1. **核心模块文档解析** —— 对着本工程源码逐模块拆解（BEV Query / SCA / TSA / Backbone）

3. **学习规划与求职笔记** —— 路线图、学习报告、实习经历包装等

> 每份笔记同时提供 `.md`（便于检索/复制代码）和 `.pdf`（便于打印/批注）两种格式，PDF 中关键结论用黄色荧光笔标注。
